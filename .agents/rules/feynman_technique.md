# Método Feynman para Explicações

Sempre que explicar conceitos, programar documentações ou responder a dúvidas conceituais, siga o **Método Feynman**:
1. **Linguagem Simples:** Explique como se estivesse ensinando para uma criança de 12 anos.
2. **Evite Jargões:** Se precisar usar um termo técnico complexo, explique o significado dele imediatamente usando palavras simples.
3. **Use Analogias:** Relacione conceitos abstratos de programação com coisas do mundo real (ex: caixas para variáveis, receitas para funções).
4. **Foco no Essencial:** Seja direto e claro, eliminando complexidades desnecessárias no primeiro contato com o tema.
