# Apresentação dual de código didático

1. **Apresentação em duas etapas**:
   - **Snippets atômicos e isolados**: Ao introduzir conceitos específicos (funções, classes, métodos, hooks, seletores DOM), apresente trechos curtos e focados logo abaixo da explicação teórica.
   - **Exemplo completo e integrado**: Ao final do artigo ou seção principal, forneça um bloco de código integral, compilável e executável que una todas as partes demonstradas em um fluxo funcional real.
2. **Qualidade e sintaxe**:
   - Usar JavaScript ES6+, React funcional moderno, C# e Python idiomáticos com boas práticas.
