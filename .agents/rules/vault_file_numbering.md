# Regra de Numeração de Arquivos do Vault

Ao criar novos arquivos ou sugerir alterações nos documentos das pastas de linguagens (como `csharp/`), sempre respeite a numeração sequencial existente no diretório:

1. **Investigar o Padrão**: Antes de criar ou renomear arquivos, liste o conteúdo do diretório para identificar o último número sequencial utilizado (ex: `01-`, `02-`, `09-`).
2. **Nova Nota**: Novas notas devem seguir a sequência imediatamente posterior ao último arquivo existente (ex: se o último é `17-LINQ buscas.md`, a nova deve ser `18-Título.md`).
3. **Sem Sobrescrita Involuntária**: Nunca mude o prefixo numérico de uma nota existente sem que isso seja explicitamente solicitado para reorganizar o índice de estudos.
