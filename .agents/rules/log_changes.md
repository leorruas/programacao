# Registro de Alterações no Log

Toda alteração de arquivos (criação, edição, renomeação, exclusão) feita no workspace/vault deve ser documentada no arquivo `log.md`.
1. **Ordem:** Escreva em ordem cronológica decrescente (as alterações mais recentes devem ser inseridas no topo, logo abaixo da introdução explicativa).
2. **Formato:** Crie uma seção com a data do dia (se não existir) e use itens de lista (`* **Tipo de Alteração**: [[Caminho/Da/Nota\|Título]]`) para documentar as modificações detalhadamente.
3. **Persistência:** Garanta que esse registro seja mantido atualizado a cada alteração aprovada e executada.
4. **Sincronização com GitHub:** Sempre que qualquer alteração for feita no vault (incluindo edições de notas, novas notas ou atualizações de regras), as mudanças devem ser commitadas e enviadas ao GitHub (`git push`) imediatamente.
