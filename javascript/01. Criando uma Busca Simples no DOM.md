# Guia Intermediário: Buscando nos Arquivos `.md` Reais do Vault 📁🔍

Neste guia, você vai aprender a fazer o JavaScript ler os **arquivos Markdown de verdade** da sua pasta usando a função `fetch()`.

---

## 🔒 Resposta sobre o Live Server: Por que ele é OBRIGATÓRIO?

**SIM! Você SEMPRE vai precisar do Live Server (ou qualquer servidor local)** quando usar o nível intermediário ou avançado.

### O motivo da segurança (Bloqueio CORS):
- Se você abrir o arquivo dando clique duplo (`file:///C:/...` ou `file:///Users/...`), o navegador **bloqueia** o JavaScript de ler arquivos no seu HD por medida de segurança contra vírus.
- Quando você usa o **Live Server** (`http://127.0.0.1:8080`), o navegador entende que é uma conexão de rede segura e autoriza o `fetch()` a ler seus arquivos `.md`.

## 🧱 Passo 1: A Lista dos Arquivos Reais (`path`)

Em vez de escrever todo o conteúdo na mão no JS, colocamos apenas o nome/título e o **caminho (path)** de onde o arquivo `.md` está guardado no seu computador:

```js
const listaDeArquivos = [
    { titulo: "Atalhos VS Code", path: "./Atalhos VS Code.md" },
    { titulo: "Guia de CSS", path: "./css/Guia de CSS.md" },
    { titulo: "Flexbox", path: "./css/Flexbox.md" },
    { titulo: "Transições e Animações", path: "./css/Transições e Animações.md" },
    { titulo: "Evolução da Programação", path: "./Evolução da Programação.md" }
];
```

## ⚡ Passo 3: Lendo os Arquivos de Verdade com `async` / `await fetch`

Para ler um arquivo sem travar o navegador, criamos uma função **assíncrona** (`async`).

```js
async function buscar(termo) {
    // 1. Limpamos a tela e o termo pesquisado
    conteinerResultados.innerHTML = "";
    const termoLimpo = termo.trim().toLowerCase();

    if (termoLimpo === "") return;

    // Colocamos um aviso visual de carregando
    conteinerResultados.innerHTML = `<div class="card"><h2>Buscando...</h2></div>`;

    let encontrouResultado = false;
    conteinerResultados.innerHTML = ""; // Limpa a mensagem de buscando

    // 2. Passamos por cada arquivo da lista
    for (const arquivo of listaDeArquivos) {
        try {
            // Fazer download/leitura do arquivo .md na pasta
            const resposta = await fetch(arquivo.path);
            const conteudoTexto = await resposta.text();

            // 3. Verificamos se a palavra digitada existe no arquivo ou no título
            const temNoTitulo = arquivo.titulo.toLowerCase().includes(termoLimpo);
            const temNoConteudo = conteudoTexto.toLowerCase().includes(termoLimpo);

            if (temNoTitulo || temNoConteudo) {
                encontrouResultado = true;
                
                // Pegamos um pedaço de 120 caracteres do arquivo para ser o resumo
                const resumo = conteudoTexto.substring(0, 120) + "...";

                // Desenhamos o card na tela!
                conteinerResultados.innerHTML += `
                    <div class="card">
                        <h2>${arquivo.titulo}</h2>
                        <div class="conteudo">${resumo}</div>
                    </div>
                `;
            }
        } catch (erro) {
            console.error("Erro ao ler arquivo:", arquivo.path, erro);
        }
    }

    // Se passou por todos e não achou nada
    if (!encontrouResultado) {
        conteinerResultados.innerHTML = `
            <div class="card">
                <h2>Nenhum resultado encontrado</h2>
                <div class="conteudo">Não encontramos nada para "${termo}".</div>
            </div>
        `;
    }
}
```

---

## 👂 Passo 4: Conectar com o Botão

```js
botaoPesquisar.addEventListener("click", () => {
    const termo = campoTexto.value;
    buscar(termo);
});
```

## 🧠 Vocabulário Novo que Você Aprendeu

1. **`async / await`**: Avisa o JS para esperar a leitura do arquivo terminar antes de ir para a próxima linha.
2. **`fetch(caminho)`**: A função nativa do JS para buscar dados/arquivos via HTTP.
3. **`resposta.text()`**: Converte a resposta bruta em texto puro `.md`.
4. **`try / catch`**: Protege o código para não quebrar se um arquivo for deletado ou sumir.

## 🌐 E quando eu hospedar no GitHub Pages?

**Vai funcionar 100% perfeitamente!** 🚀

O **GitHub Pages** é um servidor web real que roda sob o protocolo `https://`. 

Quando você subir seu projeto para o GitHub:
- O Live Server é apenas o seu "servidor de teste local" no computador.
- No GitHub Pages, o endereço será algo como `https://seu-usuario.github.io/seu-repositorio/`.
- O comando `fetch()` continuará lendo seus arquivos `.md` normalmente e qualquer pessoa com o link do seu site conseguirá pesquisar no seu Vault online!
